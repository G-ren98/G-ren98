## PyQt6 炫酷玻璃拟态仪表盘

运行步骤：

1. 创建虚拟环境（可选）
```bash
python -m venv .venv && source .venv/bin/activate
```

2. 安装依赖
```bash
pip install -r requirements.txt
```

3. 运行
```bash
python main.py
```

- 该程序使用无边框+半透明背景，依赖桌面合成器以获得最佳效果。
